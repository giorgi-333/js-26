### *`დავალებებისთვის გამოაცხადეთ შესაბამისი ცვლადები`*

# დავალება 1

თუ საათი ნაკლებია 12-ზე, დაბეჭდეთ "დილა მშვიდობისა"; თუ 12-დან 18-მდეა — "გამარჯობა"; სხვა შემთხვევაში — "საღამო მშვიდობისა".

# დავალება 2

შეამოწმეთ და დაწერეთ რიცხვი ლუწია თუ კენტი

# დავალება 3 

2 რიცხვს შორის დაწერეთ რომელია მეტი

# დავალება 4 

დაწერე პროგრამა, რომელიც ამოწმებს:
რიცხვი დადებითია, უარყოფითი თუ ნულის ტოლია.

# დავალება 5

მაღაზიას აქვს ფასდაკლება, თუ მომხმარებელი არის 14 წელზე პატარა ან  60 წელზე მეტის. დაადგინეთ ეკუთვნის თუ არა ფასდაკლება.

# დავალება 6

მოცემულია ასაკი.
დაადგინეთ რომელ ასაკშია პიროვნება:

სამუშაო ასაკი (18–65)

საპენსიო ასაკი (>65)

არასრულწლოვანია (<18)

# დავალება 7

მოცემულია ცვლადი color.
switch-ის გამოყენებით დაბეჭდეთ ფერის მნიშვნელობა.

მაგალითად:

"red" → წითელი

"green" → მწვანე

"blue" → ლურჯი

# დავალება 8 

ციფრის მიხედვით ქართულად დაწერეთ კვირის დღე (0-კვირა, 6-შაბათი) 

# დავალება 9

მოცემულია სტუდენტის ქულა (0–100).
პირობის გამოყენებით განსაზღვრე შეფასება:

90–100 → A

70–89 → B

50–69 → C

< 50 → F

# დავალება 10 

მოცემულია სამი რიცხვი.
იპოვე უდიდესი.

# დავალება 11

მოცემულია ხელფასი.
დაადგინე გადასახადის ოდენობა:

<1000 → 0%

1000–3000 → 10%

3000 → 20%
