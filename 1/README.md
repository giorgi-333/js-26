# დავალება 1

შექმენით ორი ცვლადი, შეკრიბეთ და გამოიტენეთ კონსოლში, alert-ში და დოკუმენტში

# დავალება 2

შექმენით ცვლადები პროდუქტის დასახელების, ფასის და მიტანის ღირებულების. შემდეგ კონსოლში და დოკუმენტში დაბეჭდეთ მსგავსად: `პროდუქტი: --, ფასი: --, მიტანის საფასური: --, სრული ღირებულება --.`  

ტირეების ადგილას ჩანდეს თქვენს მიერ შევსებული ცვლადების მონაცემები.

# დავალება 3

გამოიტანეთ პირველი შეტყობინება: `შეიყვანეთ სახელი`, დახურვის შემდეგ გამოიტანეთ მეორე შეტყობინება `შეიყვანეთ გვარი`, ხოლო შემდეგ დაბეჭდეთ: `გამარჯობა ` და შევსებული სახელი გვარი.

# დავალება 4

გამოიტანეთ შეტყობინება: `შეიყვანეთ მანძილი მილებში: ` და შევსების შემდეგ დაბეჭდეთ `X მილი არის Y კილომეტრი`  
X არის შევსებული ციფრი.  
Y არის მილი გადაყვანილი კილომეტრში.

# დავალება 5 

გამოიტანეთ დიალოგები სახელის, დაბადების წლის და მიმდინარე წლის შესავსებად. შევსების შემდეგ დაწერეთ შევსებული სახელი და თქვენ ხართ X (დაანგარიშებული) წლის.
